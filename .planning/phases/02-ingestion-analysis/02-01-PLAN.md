Rename `_split_messages` to handle image content blocks. When a `Message` has `images`, build Anthropic multi-part content blocks:

Update the existing `_split_messages` function to:
```python
def _split_messages(messages: list[Message]) -> tuple[str, list[dict[str, Any]]]:
    """Separate system message from user/assistant messages, handling image blocks."""
    system = ""
    rest: list[dict[str, Any]] = []
    for msg in messages:
        if msg.role == "system":
            system = msg.content
        elif msg.images:
            # Build multi-part content with image blocks first, then text
            content_parts: list[dict[str, Any]] = []
            for img_b64, media_type in msg.images:
                content_parts.append({
                    "type": "image",
                    "source": {
                        "type": "base64",
                        "media_type": media_type,
                        "data": img_b64,
                    },
                })
            content_parts.append({"type": "text", "text": msg.content})
            rest.append({"role": msg.role, "content": content_parts})
        else:
            rest.append({"role": msg.role, "content": msg.content})
    return system, rest
```

Update the return type annotation of `_split_messages` from `tuple[str, list[dict[str, str]]]` to `tuple[str, list[dict[str, Any]]]`.
