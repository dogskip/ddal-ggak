# Interpreting evidence

A native test report, browser capture, canonical run and offline replay prove different things.
Name the observed runtime and checks. A valid replay checks sealed bytes; it does not rerun tests.
A current-source gate checks source agreement with saved evidence; it does not authorize publishing.

Read additional ranges only when the current bounded excerpt cannot answer the question.
Preserve original action codes and distinguish an unmet target, a preservation regression,
missing execution authority, an unavailable environment and an integrity failure.
