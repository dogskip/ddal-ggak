---
name: design
description: Generate a design package from a project idea with DDK Design Studio. Use when the user requests specifications or a design package.
---

Confirm the idea and output directory with the user. Run:

```bash
ddk design new "<idea>" --non-interactive
```

This command can call a paid provider. Obtain approval for provider use and budget before running it.
Inspect the generated files under `design-package/` before reporting completion.
Document generation is not implementation acceptance or a ready verdict.
