# 검증 가능한 화면 변경: 3심 검토 기록

검토 기준일: 2026-10-14. 최종 상태: **설계 문서 확정**. 3심 최종 재검토의 미해결 중대 지적은 0개다.

확정 방향은 기존 React·TypeScript 변경의 독립 검사와 선택 수정, 현재 파일 저장의 보강이다. 관련 기능·9개 논리 테이블·21개 자료 정의의 203개 필드·관계·상태·복구·실행 수용 기준을 명시했다. 첫 구현에 실제 DB·서버를 추가하지 않는 이유와 재검토 조건도 함께 확정했다. 제품 출시나 경쟁 우위의 확정은 별도 실행 조건이다.

## 범위와 판단의 의미

요청은 경쟁력·실용성·정확성·원본 보호·편의성·유지보수·재사용·중복 제거·확장성과 불필요한 구성 제거를 만족하는 목표 설계의 문서화다. 설계 정합성의 확정과 실제 제품의 성능·안전·표준 인증을 구분한다. 사용자의 100점 요구는 결함을 찾고 보강할 품질 목표이며 실측 없이 부여하는 점수가 아니다.

문서의 사용 여부는 인터넷 공식 근거와 기존 구현, 반례, 필드·상태·수용 기준을 대조해 판단한다. 심사 담당은 각자 독립적으로 대상 파일을 확인했다. 첫 두 심사의 초기 SHA256은 당시 관찰한 대상이며 문서 수정 후의 전체 버전 검토는 3심이 담당한다. 보관하지 않은 초기 버전의 전체 재현까지 주장하지 않는다.

## 3심: 수정 설계 전체와 증거의 최종 확인

담당: third_review. [3심 원문](2026-10-14-third-review.md). 초기 독립 검토는 높음 4건·중간 3건의 보강을 요구했다. 아래 대응 후 전체 묶음을 독립 재검토해 **문서확정가능**으로 판단했다. 관련 공식 자료도 별도로 재확인했다.

| R3-01 표의 열 파손·nullable 제약 누락 | 비null 분기의 제약 생성·구분자 escape·모든 열 값과 열수 비교 | VCT-13 |

| R3-03 상대 URL의 외부 origin 우회 | 역슬래시·제어문자 거부·해석 후 origin 확인·redirect와 하위 요청 경계 | VCT-09·20 |

| R3-06 비용·회차·반영 관계 누락 | settled usage·가격 kind·회차 참조·중복 경로·종료 상태 검사; 실제 초과는 blocked로 보존 | VCT-11~13 |

수정 전 검사는 추가 반례 22개를 포함한 76개 중 57개만 기대와 일치했다. 잘못 허용한 17개와 잘못 거부한 빈 입력 2개를 [수정 전 기록](2026-10-14-third-validation-before-fix.json)에 보존했다. 이 수치는 제품 결함률이 아니라 문서 검사기의 반례 재현 결과다. 수정 후에는 시간 상한 관련 예시 3개도 추가했다.

최종 재검토 담당자는 문서 검사 79/79, 독립 변형 33개 기대 불일치 0개, 필드 203개 별도 대조 오류 0개, 잘못된 표 5변형의 거부, Ruff 통과를 직접 확인했다. 최종 대상 17개 SHA256도 직접 대조했다. 시간·비용·격리·원본 반영의 실제 제품 시험은 이 결과에 포함하지 않는다. 정확한 대상 해시·명령·판단은 3심 원문 §7에 보존한다.

## 문서 검사와 현재 제품의 경계

[문서 검사기](check_verified_change_design.py)는 고정 예시·schema·관계·필드표·요구 추적·로컬 참조를 확인한다. [검사 결과](2026-10-14-document-validation.json)의 범위는 문서 정합성이다. 예시의 해시·성공 기록은 합성 값이다.

[현재 기준 기록](2026-10-14-baseline.json)은 앞선 실행 결과와 현재 소스 해시의 일치를 기록한다. 새 설계를 구현하거나 모델·격리·브라우저·비용·생산성을 실행 검증한 자료가 아니다. 실제 구현·효과 증거는 0으로 유지한다. 제품 출시 조건은 [검증 설계](../36-verified-change-verification.md)에 별도로 정의한다.

## 최종 산출물과 보존

- [목표 설계](../34-verified-change-design.md): 사용자 절차·책임·실행·판정·반영·관련 기능·전환.
- [저장 설계](../35-verified-change-storage.md): DB 판단·논리 테이블·모든 필드·관계·보존·잠금·복구.
- [수용 기준](../36-verified-change-verification.md): 요구 20개와 실제 실행 시험 30개의 대응·효과 평가·중단 조건.
- [기존 파일 목록](2026-10-14-workspace-before.json)과 [보존 결과](2026-10-14-preservation.json): 기존 458개 파일의 존재·mode·내용 유지, 기준 소스 154개 해시 일치.
- [최종 해시 목록](2026-10-14-artifact-manifest.json): 신규 문서·계약·검토·증거의 파일별 SHA256와 최종 검사 범위.

3심 확정 후에는 이 요약의 최종 상태·증거 연결, 자동 검사 결과와 보존 목록, 최종 해시 목록만 완성했다. 목표·저장·수용·용어·schema·예시·검사기의 핵심 7개 파일은 3심의 최종 SHA256와 일치한다. 최종 해시 목록은 자기 파일을 제외해 계산한다. 기존 소스·시험·설정·문서는 변경하지 않았다. 현재 타입 오류·브라우저 시험 실패의 해결과 D0~D4 실행은 구현 단계의 조건으로 유지한다.
