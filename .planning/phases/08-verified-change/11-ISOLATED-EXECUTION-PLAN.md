# 실제 격리 검사 구현 계획

**Goal:** 기본 검사 경로에서 고정한 로컬 이미지로 앱과 검사 작업을 분리해 실행하고 실제 결과와 정리 여부를 반환한다.
**Architecture:** 기존 LocalDockerIsolation의 정책 확인 뒤에 한정된 실행 연결을 추가한다. 앱은 검사 기준·인증·Docker 소켓을 받지 않으며 검사 작업은 앱 파일을 받지 않는다. 명령 결과의 해석과 화면 검사는 기존 구현을 재사용하고 원본 대신 소유한 사본만 실행한다.
**Tech Stack:** Python 3.12, 기존 Docker CLI·Playwright·Pillow·JSON Schema, 현재 파일 저장 계약.
**Decisions settled:** 기존 D2와 VCT-09·20~22·28·29의 실행 경계를 유지한다. 별도 서버·DB·실행 대기열을 추가하지 않는다. 기존 사용자 승인 범위에서 진행하며 미해결 제품 선택은 없다.
**Verification:** 실패 시험 → 최소 구현 → 집중 회귀 → 실제 Docker·headless 화면·취소·하위 실행 정리 → 전체 일반·화면 시험 → 타입·형식·배포 파일 검사.

## 수용 조건

| ID | 요구 | 검증 |
|---|---|---|
| ISO-01 | 기본 경로에서 실제 실행, 호스트 자동 대체 없음 | 기본 서비스·명령 연결과 실행기 없음 거부 |
| ISO-02 | 이미지 ID 고정·로컬 전용·정책 확인 후 실행 | 가변 태그·정책 불일치·이미지 누락 거부 |
| ISO-03 | 앱 명령과 검사 기준 분리 | 앱에서 criteria/results/socket 접근 불가, 검사에서 workspace 접근 불가 |
| ISO-04 | 기존 화면 검사 재사용 | 실제 이동·입력·회귀·화면 자료·외부 요청 차단 |
| ISO-05 | 원본과 승인 후보 일치 | 사본의 실행 전후 내용·목록·권한 대조, 원본 해시 보존 |
| ISO-06 | 요청·단계 시간과 출력·자료 상한 유지 | 경계값·초과·미정 출력 시 후속 실행 중지 |
| ISO-07 | 실패·취소와 반복 실행에서 소유 작업 정리 | 하위 실행 생성 후 중단, 컨테이너 잔존 없음, 다른 컨테이너 보존 |
| ISO-08 | 환경 자료를 실제 실행과 대조 | 이미지·실행기·OS·Python·Node·브라우저·글꼴·잠금 파일·정책 일치 |
| ISO-09 | 설치한 배포 파일에서도 동작 | 검사 작업 소스·schema·정책 포함 및 설치 후 확인 |

## 작업 순서

- 기존 정책 실행기에 검증된 앱/검사 명령 통로를 추가하고 실패·취소 정리 시험을 먼저 확인한다.
- 고정 검사 작업을 읽기 전용 기준 폴더에 준비한다. 프로젝트가 공급한 Python 모듈이나 시작 파일을 가져오지 않는다.
- 기본 evaluator에 격리 조율을 연결한다. 명령 해석·화면 판정·자료 계약은 기존 구현을 사용한다.
- 실제 실행 환경과 승인한 환경의 불일치를 통과시키지 않는다. 이미지 준비는 실행과 분리하며 검사 중 내려받기·설치를 하지 않는다.
- 실제 Docker E2E를 opt-in으로 추가하고 동작 성공·회귀·차단·취소·반복 정리를 증명한다.
- 요구 추적, 실패 반례, 최종 회귀의 세 단계에서 검토한다. 자체 검토와 독립 검토를 구분해 기록한다.

## 근거와 제한

- [Docker 실행 옵션](https://docs.docker.com/reference/cli/docker/container/run/): 고정 이미지, 읽기 전용 파일 체계, 자원 제한, init, 네트워크 선택.
- [Playwright Docker](https://playwright.dev/python/docs/docker): 별도 사용자와 seccomp, 브라우저와 Python 도구의 판 일치. 호스트 IPC 공유·권한 확대를 해결책으로 사용하지 않는다.
- 현재 Docker 실행기는 중지 상태였으며 개발 검증을 위해 기존 OrbStack을 시작했다. 기존 다른 컨테이너를 변경하거나 정리하지 않는다.
- 개발 검증용 이미지 준비와 내려받기는 실제 검사의 자동 설치 권한과 구분한다. 유료 모델 요청·main 병합·제품 효과 주장은 포함하지 않는다.
